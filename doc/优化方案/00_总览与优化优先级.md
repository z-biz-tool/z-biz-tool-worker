## 本仓是什么

AI 任务看板。第一个管理条是 **Agent 员工**：每个 Agent 启动一个本地进程跑 LLM
（Claude Code 等），任务卡在多条管理条间拖拽表达状态，Agent 主动领取未结束的任务。

- 形态：Tauri 2 + React 19 + antd 6 + Zustand 5，Rust 后端
- 规模（实测）：前端 ts/tsx **18** 个文件、后端 rs **9** 个文件
- 视图：Kanban / List / Gantt / Calendar / Dashboard / Documents，外加 WorkflowEditor

## 一句话结论

**全组织风险面最高的仓，测试网最薄。**

- 风险面：`agent_proxy.rs` 直接用 `std::process::{Child, Command, Stdio}` 拉起并
  kill 子进程（该文件第 9 行还特意写明"我们故意不用 tauri-plugin-shell"）。
- 测试网：Rust **7** 条（实测 `cargo test` → `7 passed / 0 failed`），
  前端 **1** 个测试文件 / **54** 条用例（实测 `npm test` → `tests 54 / pass 54 / fail 0`）。
- 另有 5 个视图组件（`GanttView` / `CalendarView` / `DashboardView` /
  `DocumentsView` / `WorkflowEditor`）**零测试**。

这个组合意味着：改坏拖拽流转、Gantt 时间轴换算、或者子进程回收，
Rust 侧不会被任何一条现有检查挡住；前端 54 条全部集中在 `taskFilters`
这一个纯函数工具上，够不到视图。

## 优先级

### P0 —— 子进程生命周期（本仓独有的高危面）

`agent_proxy.rs` 直接 `Command::new` 拉进程。现有 1 条 `spawn_and_kill_lifecycle`
覆盖不到这些：

- **P0-1 孤儿进程**：Agent 被删除 / 应用异常退出后，子进程是否一定被回收？
  `Child` 句柄在进程崩溃时不会被 kill ⇒ 可能留下跑着的 LLM 进程持续烧 token。
- **P0-2 `which node` 依赖外部 PATH**（第 97 行）：PATH 被改或 node 不在 PATH 时
  行为是什么，现在是报错还是静默？
- **P0-3 stdout/stderr 无上限**：`Stdio::piped()` + 持续读取的子进程，
  输出量大时的内存与背压行为未验证。

### P1 —— 状态流转无测试网

任务从 `doing` → `review` → `done` 是本仓的产品核心，但这条主链上
**没有一条端到端测试**。`db.rs` 的 4 条测的是 rename / upsert 的字段保持，
不是流转规则。

- **P1-1 流转规则测试**：非法跳转（如 `done → doing`）当前是被拒绝还是被静默接受？
- **P1-2 并发领取**：两个 Agent 同时领同一任务时的竞态（这是"Agent 主动领取"
  设计里的核心并发点）。
- **P1-3 五个视图的渲染测试**：至少 Gantt（时间轴换算）与 Calendar（月边界）
  有纯函数部分，应可测。

### P2 —— 工程基线

- **P2-1 本机跑 typecheck 必须先 `npm ci`**：`node_modules` 缺失时 `npx tsc` 会
  **绕过 lockfile 直接抓最新版**（本机抓到 **7.0.2**，lockfile 锁的是 **5.9.3**），
  而 TS 7 已移除 `baseUrl` ⇒ 报出两条**并不存在**的 tsconfig 错误。
  用 `./node_modules/.bin/tsc --noEmit` 或 `npm run typecheck` 才是真结果（实测 rc=0）。
  详细经过与判别式见 01 的 C1 —— **本轮真踩过，差点把环境假象当既存缺陷写进方案。**
- **P2-2 本地构建需两步**：`tauri.conf.json` 的 `bundle.resources` 引用
  `../agent-proxy/dist`，而 `dist` 被 `.gitignore` 挡住。照 `ci.yml` 的
  `npm run build:all` 才编得出来；只跑 `cargo test` 会红在
  `resource path ... doesn't exist`。**这是既存坑，本轮已踩过一次**，
  已写进 `worker` 的提交信息。
- **P2-3 无 agent-proxy 锁文件**：设计如此（见 `ci.yml` 注释），但意味着
  `agent-proxy` 的依赖版本不受约束。已在 `.gitignore` 里忽略生成的锁文件。
